# ReproLoop 문서 안내

문서는 공통 자료와 담당자별 자료로 구분한다.

```text
docs/
├─ shared/          두 사람이 현재 함께 사용하는 문서
├─ a-용준/          인원 A(용준) 담당 문서
│  ├─ plans/        작업 계획
│  ├─ reports/      완료·점검 보고서
│  ├─ guides/       설명·테스트 가이드
│  └─ archive/      더 이상 사용하지 않는 A 문서
├─ b-신정/          인원 B(신정) 담당 문서
│  ├─ plans/
│  ├─ reports/
│  ├─ guides/
│  └─ archive/
└─ archive/         담당자가 없는 공통 과거 문서
```

현재 파일이 없는 하위 디렉터리는 만들지 않는다. 해당 종류의 문서가 처음 생길 때 디렉터리를 함께 만든다.

## 분류 규칙

- 두 사람이 현재 함께 참고하는 기준 문서는 `shared/`에 둔다.
- 담당자 작업 계획은 해당 담당자의 `plans/`에 둔다.
- 작업 결과와 검증 기록은 해당 담당자의 `reports/`에 둔다.
- 현재 사용하는 설명서와 테스트 방법은 해당 담당자의 `guides/`에 둔다.
- 대체됐거나 더 이상 사용하지 않는 문서는 담당자별 `archive/`에 둔다.
- 담당자가 없는 공통 과거 문서는 최상위 `archive/`에 둔다.
