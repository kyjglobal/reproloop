# A Day 6 제보 목록·상세 통합 입문자 가이드

## 1. Day 6에서 끝내는 흐름

Day 5에는 로그인한 개발자가 프로젝트를 선택하고 제보 목록을 확인하는 화면을 만들었다.
Day 6에는 B가 만든 제보 상세 화면을 목록과 연결하고 다음 흐름을 하나로 검증한다.

```text
Discord /bug 제출
→ 프로젝트 선택
→ 제보 목록과 필터
→ 제보 상세와 상태 이력
→ 기존 목록 조건으로 돌아가기
```

Day 6은 새로운 대형 화면을 추가하는 단계가 아니다. A의 목록 화면과 B의 상세 화면이 실제 사용 흐름에서 끊기지 않는지 확인하고 필요한 부분을 보완하는 단계다.

## 3. 이번에 보완한 동작

### 목록 조건을 상세 화면까지 유지

사용자가 다음 조건으로 목록을 보고 있었다고 가정한다.

```text
상태: 신규
검색어: freeze
페이지: 다음 페이지
```

기존에는 상세 화면에서 `제보 목록`을 누르면 필터가 없는 기본 목록으로 돌아갔다. 이제 목록 주소를 상세 링크의 `returnTo` 값으로 전달한다. 상세 화면의 `제보 목록`을 누르면 상태, 빌드, 검색어, 페이지 조건이 유지된다.

관련 파일:

- `apps/web/src/app/projects/[projectId]/reports/page.tsx`
- `apps/web/src/app/projects/[projectId]/reports/[reportId]/page.tsx`
- `apps/web/src/server/reports/navigation.ts`

### 안전한 복귀 주소 검사

브라우저 주소의 `returnTo`는 사용자가 수정할 수 있다. 따라서 아무 주소나 그대로 사용하지 않는다.

- 현재 프로젝트의 `/projects/{projectId}/reports`만 허용한다.
- 다른 프로젝트의 목록 주소는 거부한다.
- 외부 사이트 주소는 거부한다.
- 잘못된 값은 현재 프로젝트의 기본 목록 주소로 바꾼다.

### 로그인 후 원래 상세 화면으로 복귀

상세 화면을 열다가 로그인이 필요해진 경우, 로그인 후 프로젝트 목록이 아니라 원래 열었던 상세 화면으로 돌아가도록 callback 주소를 보완했다.

## 4. 자동 테스트에서 확인한 내용

`apps/web/test/report-navigation.test.ts`에서 다음을 확인한다.

- 필터가 포함된 목록 주소가 상세 링크에 전달된다.
- 올바른 현재 프로젝트 목록 주소가 복원된다.
- 외부 주소가 거부된다.
- 다른 프로젝트의 목록 주소가 거부된다.

개발 DB 통합 테스트에서는 임시 조직, 프로젝트, 빌드와 제보를 만든 후 다음을 확인했다.

- 제보 목록 query가 실제 PostgreSQL에서 동작한다.
- 제보 상세와 상태 이력이 실제 PostgreSQL에서 조회된다.
- 테스트 종료 후 임시 데이터가 정리된다.

## 6. 실제 Discord 통합 확인

자동 테스트가 통과해도 실제 Discord 계정과 `/bug` 명령의 연결은 한 번 확인해야 한다.

1. Discord 테스트 서버에서 `/bug`를 실행한다.
2. 테스트 프로젝트와 활성 빌드를 선택한다.
3. 실제 현상, 예상 결과, 재현 단계, 플랫폼과 빈도를 입력한다.
4. 접수된 `BUG-{번호}`를 기억한다.
5. 웹에서 Discord 계정으로 로그인한다.
6. `/projects`에서 같은 프로젝트를 선택한다.
7. 목록에서 방금 접수한 BUG 번호가 표시되는지 확인한다.
8. 상태 또는 검색 필터를 적용한다.
9. BUG 번호나 제목을 눌러 상세 화면을 연다.
10. Discord에서 입력한 내용과 최초 상태 이력이 같은지 확인한다.
11. `제보 목록`을 눌러 기존 필터가 유지되는지 확인한다.
12. 상세 화면을 새로고침해도 같은 내용이 표시되는지 확인한다.

## 7. 오류 상황 확인

다음 화면도 정상적인 제품 동작이다.

| 상황 | 기대 화면 |
|---|---|
| 로그인하지 않음 | Discord 로그인 안내 |
| 조직 멤버가 아님 | 프로젝트 권한 없음 |
| 존재하지 않는 제보 | 제보를 찾을 수 없음 |
| 목록 결과가 없음 | 표시할 제보가 없음 |
| DB 연결 실패 | 목록 또는 상세를 불러오지 못했다는 안내 |

390px 너비의 모바일 화면에서는 오류 안내가 가로로 넘치지 않아야 한다. 긴 제목, 재현 단계와 Discord 이름도 화면 밖으로 밀리지 않는지 실제 제보로 확인한다.
