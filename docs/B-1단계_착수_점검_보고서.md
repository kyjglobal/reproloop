### 테스트 2. 의존성 설치와 기본 검사

### 테스트 3. 환경변수 파일 준비

1. 루트 `.env.example`을 루트 `.env`로 복사한다.
2. A에게 받은 실제 값을 `.env`에만 입력한다.
3. 아래 명령으로 Git 추적에서 제외되는지 확인한다.

성공 기준:

주의: `.env` 내용을 터미널에 출력하거나 문서·PR에 붙이지 않는다.

### 테스트 4. 필요한 키가 채워졌는지 값 노출 없이 확인

`.env`에 값을 입력한 뒤 아래 스크립트를 실행한다.

```powershell
$required = @(
  'DATABASE_URL',
  'SUPABASE_URL',
  'SUPABASE_SECRET_KEY',
  'SUPABASE_STORAGE_BUCKET',
  'AUTH_SECRET',
  'AUTH_DISCORD_ID',
  'AUTH_DISCORD_SECRET',
  'DISCORD_APPLICATION_ID',
  'DISCORD_PUBLIC_KEY',
  'DISCORD_BOT_TOKEN'
)

$values = @{}
Get-Content .env | ForEach-Object {
  if ($_ -match '^\s*([A-Za-z_][A-Za-z0-9_]*)\s*=\s*(.*)$') {
    $values[$matches[1]] = $matches[2]
  }
}

$required | ForEach-Object {
  $configured = $values.ContainsKey($_) -and
    -not [string]::IsNullOrWhiteSpace($values[$_])
  "$_=" + $(if ($configured) { 'configured' } else { 'missing' })
}
```

성공 기준: 모든 항목이 `configured`로 표시된다. 이 스크립트는 실제 값을 출력하지 않는다.

### 테스트 5. Supabase 연결 확인

`DATABASE_URL`을 입력한 후 다음을 실행한다. `pnpm --filter`는 `packages/db`에서 스크립트를 실행하므로, 루트 `.env`의 `DATABASE_URL`만 현재 process에 안전하게 주입한다.

```powershell
$databaseLine = Get-Content .env |
  Where-Object { $_ -match '^\s*DATABASE_URL\s*=' } |
  Select-Object -First 1
$env:DATABASE_URL = ($databaseLine -replace '^\s*DATABASE_URL\s*=\s*', '').Trim().Trim('"').Trim("'")
pnpm --filter @reproloop/db db:studio
Remove-Item Env:DATABASE_URL
```

Drizzle Studio가 실행되고 DB schema를 읽으면 연결 정보가 유효하다. 연결만 확인한 뒤 `Ctrl+C`로 종료한다. 아직 migration 경로를 결정하기 전에는 `db:migrate`를 실행하지 않는다.

### 테스트 6. 기존 migration 적용 여부 확인

Supabase Dashboard의 SQL Editor에서 다음 query를 실행한다.

```sql
select id, hash, created_at
from drizzle.__drizzle_migrations
order by created_at;
```

결과 해석:

- `drizzle.__drizzle_migrations`가 없거나 결과가 비어 있음: Drizzle migration 미적용 가능성이 높으므로 경로 A 후보
- 행이 하나 이상 있음: 기존 migration 적용 가능성이 있으므로 경로 B 선택

추가로 현재 DB enum을 확인한다.

```sql
select e.enumsortorder, e.enumlabel
from pg_type t
join pg_enum e on e.enumtypid = t.oid
where t.typname = 'report_status'
order by e.enumsortorder;
```

현재 초기 migration이 적용됐다면 다음 값이 보인다.

```text
new, triaged, in_progress, fixed, closed, duplicate
```

SQL 결과의 행 수와 enum 값만 공유하면 된다. database URL이나 화면 전체 screenshot은 공유하지 않는다.

### 테스트 8. GitHub 최신 상태 확인

네트워크 fetch가 이 점검 환경에서는 시간 초과됐으므로 사용자의 터미널에서 실행한다.
